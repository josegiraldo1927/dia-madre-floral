
# Proyecto Día de la Madre 💐

## Cómo usar

1. Cada estudiante abre su archivo dentro de:
   /estudiantes/

2. Cambia:
- Nombre de la mamá
- Carta
- Fotos
- Música

3. Para subir a GitHub:
- Crear repositorio
- Subir archivos
- Activar GitHub Pages

## GitHub Pages
Settings → Pages → Deploy from branch
